MEAL PLANNER - dispensa, ricette e piano dei pasti (programma desktop)

Requisiti: Python 3.10 o superiore. Nessuna libreria esterna (solo libreria standard, Tkinter incluso;
su Linux, se manca, installa il pacchetto di sistema python3-tk).

AVVIO:   python gui.py
Al primo avvio crea il database inventario.db nella stessa cartella.

COME INIZIARE (schede della finestra)
 1. Profilo   - imposta sesso, attivita' e obiettivo: serve per le kcal giornaliere.
 2. Dispensa  - aggiungi i prodotti (la prima volta che inserisci un nome nuovo ti chiede unita' e valori per 100 g).
 3. Ricette   - inserisci le ricette dal modulo oppure importale da file .json / .csv.
 4. Piano     - "Proponi piano", poi "Salva piano"; quando cucini, "Segna come cucinato"
                (indica quante porzioni: le altre diventano avanzi). Puoi bloccare o saltare un pasto.
 5. Spesa     - mostra cosa manca (consumi oltre la disponibilita' e ingredienti dei piani).

IMPORT RICETTE (le quantita' sono per UNA porzione; unita': g, kg, ml, L, pz, cucchiaio, cucchiaino)
 JSON: [{"nome": "Riso e pollo", "pasti": ["pranzo", "cena"],
         "ingredienti": [{"prodotto": "Riso", "quantita": 100, "unita": "g"}]}]
 CSV (separatore ; o ,): ricetta;pasti;prodotto;quantita;unita;quanto_basta   (pasti separati da |)

RIGA DI COMANDO (facoltativa)
 python motore.py ricette | giorno ... | profilo ...
 python pianificatore.py giorno | settimana | spesa
 python ricette.py importa file.json
